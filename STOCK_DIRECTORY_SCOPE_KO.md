# WUMI expanded US ticker search
The public file `/stocks/us_sec_directory_v1.json` is an **English** company name/ticker/exchange directory based on the U.S. SEC public EDGAR ticker association.
It contains no quotes, balances, user holdings or login information.
Source: https://www.sec.gov/search-filings/edgar-search-assistance/accessing-edgar-data
Reuse policy: https://www.sec.gov/about/privacy-information
The SEC does **not** guarantee scope or accuracy. Some listings/ETFs are not covered.
The curated Korean-name feed `/stocks/ko_names_v1.json` takes precedence in the app. Do not fabricate Korean translations. Unlisted Korean securities remain covered by the app's local market catalog.
If the SEC cannot be reached during an update, the last successful JSON snapshot remains untouched.
